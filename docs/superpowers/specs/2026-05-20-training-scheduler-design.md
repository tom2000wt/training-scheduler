# 培训机构教师日程行事历 — 设计方案

## 概述

为K12课外辅导机构的授课老师开发一款桌面端日程行事历系统，帮助老师管理上课时间、教室、科目安排，支持课时统计和调课/请假。

**核心约束：**
- 纯本地运行，不联网
- 一键安装，零配置
- 面向无计算机基础的用户

---

## 一、技术架构

## 二、功能模块

### 1. 日历视图
- 周视图（默认）：显示本周每天课程，每课格显示科目、教室、班级
- 月视图：概览整月排课密度
- 日视图：查看某天详细时间表
- 按科目/班级用颜色区分

### 2. 课程管理
- 手动新增/编辑/删除课程（科目、年级、班级、教室、起止时间）
- 支持单次课和重复课（每周/每两周）
- 拖拽课程调整时间
- 调课：标记某节课调至其他时间，记录原因
- 停课/请假：取消某次课并标记原因
- 假期/停课日批量设置

### 3. Excel导入
- 支持预定义模板导入课表
- 导入时预览数据、冲突检测（教室/时间冲突）
- 支持追加导入和替换导入

### 4. 课时统计
- 按月份/学期统计授课课时
- 按科目、班级分类汇总
- 报表导出Excel

## 三、数据模型

```
courses（课程模板表）
├─ id              INTEGER PRIMARY KEY
├─ subject         科目（如"数学"）
├─ grade           年级（如"初三"）
├─ className       班级名称
├─ classroom       教室
├─ startTime       开始时间（HH:MM）
├─ endTime         结束时间（HH:MM）
├─ repeatType      重复类型：none / weekly / biweekly
├─ startDate       课程起始日期
├─ endDate         课程结束日期（可为空）
├─ color           课程颜色标记
├─ status          状态：active / archived
└─ notes           备注

schedule_exceptions（调课/停课记录）
├─ id              INTEGER PRIMARY KEY
├─ courseId        关联课程ID
├─ originalDate    原上课日期
├─ newDate         新日期（停课则为空）
├─ newStartTime    新开始时间（停课则为空）
├─ newEndTime      新结束时间（停课则为空）
├─ type            类型：rescheduled / cancelled
└─ reason          原因

holidays（假期/停课日）
├─ id              INTEGER PRIMARY KEY
├─ date            日期
└─ label           说明
```
